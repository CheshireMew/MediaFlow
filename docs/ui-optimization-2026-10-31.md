| 位置 | 结果 |
| --- | --- |
| 公共样式 | 统一深色底色、分隔线、输入框和焦点颜色，使用 Windows 系统字体；减少光晕、重阴影、装饰渐变和持续闪烁。 |

| 编辑器 | 未载入媒体时收起空白时间轴，让字幕导入提示和预览区获得更多空间；空字幕使用同一图标库；选中行使用底色与细轮廓。 |
| 设置 | 设置项按分隔线组织，说明和按钮可换行；服务商使用有表头的表格，长名称和模型名换行，长地址截断并保留完整提示；服务商弹窗内容可滚动，底部操作保持可见。 |
| 键盘和动效 | 全局提供可见的键盘焦点、文本选择和输入光标样式；尊重系统减少动态效果的偏好；文件拖入时提供高亮反馈。 |
